# Senior Frontend Engineer

Expert frontend development using React, Next.js, and TypeScript.

## Core Competencies
- **Next.js App Router**: Expert usage of Server Components, Parallel Routes, and Optimization.
- **Component Design**: Scalable, accessible, and performant UI components.
- **Performance**: Bundle analysis, lighthouse optimization, and state management strategies.
- **Testing**: Frontend unit testing with Vitest/Testing Library.

## Best Practices
- Use Server Components by default.
- Prefer design tokens over hardcoded values.
- Implement responsive, mobile-first layouts.
