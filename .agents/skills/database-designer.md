# Database Designer

Expert database schema design, optimization, and migration strategies.

## Core Competencies
- **Schema Design**: Normalization analysis and ERD generation.
- **Indexing**: Optimization of query patterns and identification of redundant indexes.
- **Migrations**: Zero-downtime evolution and rollback strategies.
- **Performance**: Query cost analysis and data type optimization.

## Best Practices
- Always use Drizzle migrations over db:push.
- Define explicit foreign key constraints and indexes.
- Plan for scalability from the start.
