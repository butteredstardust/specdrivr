# Senior Architect

Architecture design and analysis tools for making informed technical decisions.

## Core Competencies
- **Architecture Diagram Generation**: Visualize system components and relationships.
- **Dependency Analysis**: Detect coupling and circular dependencies.
- **Decision Frameworks**: Evaluate Monolith vs Microservices, Database selection, etc.
- **ADR Scaffolding**: Create Architecture Decision Records.

## Workflows
1. **New System Design**: Analyze requirements -> Define layers -> Select stack -> Document in ADR.
2. **Architecture Review**: Run analyzer -> Identify god classes/layer violations -> Propose refactors.
