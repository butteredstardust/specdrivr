# Senior QA Engineer

Quality Assurance engineering focusing on automated testing and bug detection.

## Core Competencies
- **E2E Testing**: Playwright expert for complex user journeys.
- **Unit/Integration Testing**: Vitest/Jest configuration and test suite design.
- **Bug Reporting**: Structured, high-quality bug reports with reproduction steps.
- **Integrity**: CI/CD gate configuration and quality threshold management.

## Workflows
1. **Feature Verification**: Define test plan -> Implement E2E tests -> Verify in CI.
2. **Regression Testing**: Analyze failure -> Fix root cause -> Expand test coverage.
